# Security

Report a vulnerability privately with GitHub's
[Report a vulnerability](https://github.com/surface-ai-code/claude-plugins/security/advisories/new)
form, or email hello@surface-ai.io. Please don't open a public issue.

This covers the plugin and the Surface MCP server at `https://mcp.surface-ai.io/mcp/`.

If a management key leaks, revoke it under
[Settings → Developers](https://app.surface-ai.io/settings/developers); it stops working at once.
